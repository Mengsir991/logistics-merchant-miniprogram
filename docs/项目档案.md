## 四、已用组件与接口

### 自定义组件

| 组件 | properties | events | 用途 |

### 云函数

| 云函数 | action | 入参 | 返回 |
|---|---|---|---|
| `auth` | `login` | — | `{ openid, merchant }`（merchant 不含密钥字段） |
| `orderApi` | `stats` | — | `{ today, pendingPrint, exception, total }` |
| `orderApi` | `list` | `{ status, keyword, page, size }` | `{ total, page, hasMore, list }` |
| `orderApi` | `detail` | `{ id }` | 运单对象 |
| `orderApi` | `createBatch` | `{ rows[], fileName }` | `{ batchId, total, successCount, failCount, failed[] }` |
| `orderApi` | `createWaybill` | `{ id }` | `{ waybillNo, label }` |
| `orderApi` | `markPrinted` | `{ ids[] }` | `{ updated }` |
| `orderApi` | `cancel` | `{ id }` | `{ id }` |
| `orderApi` | `trace` | `{ id }` | `[{ time, desc }]` |

统一返回 `{ code, msg?, data }`，`code === 0` 为成功。前端封装在 `utils/cloud.js`。

### 数据模型

```js
// merchants
{ _id, openid, unionid, name, contact, phone, role, status, expressAccounts[], defaultSender{}, createdAt, lastLoginAt }

// orders
{ _id, merchantId, openid, shopOrderNo, sender{}, receiver{}, goods{weight,count},
  expressCode, expressName, waybillNo, label{}, status, printStatus, importBatchId, createdAt, updatedAt }

// import_batches
{ _id, merchantId, openid, fileName, total, successCount, failCount, status, createdAt, finishedAt }
```

### 运单状态机

`pending_waybill`（待取号）→ `pending_print`（待打印）→ `printed`（已打印）→ `shipped`（运输中）→ `signed`（已签收）
旁支：`exception`（异常）、`cancelled`（已取消，终态）

### 已接入 wx API

`wx.cloud.*`、`wx.chooseMessageFile`、`wx.getFileSystemManager().readFile`、`wx.canvasToTempFilePath`（canvas 2d）、`wx.saveImageToPhotosAlbum`、`wx.openSetting`、`wx.setClipboardData`、`wx.getPrivacySetting`、`wx.openPrivacyContract`、`wx.createSelectorQuery`、BLE 系列（`openBluetoothAdapter`/`createBLEConnection`/`setBLEMTU`/`writeBLECharacteristicValue`）。

> 隐私类接口（`getPrivacySetting`、`openPrivacyContract`）需较低基础库版本支持，**具体最低版本以官方文档核实**。
